# Extract Financial Forecast Output

CSV files extracted from the City of Pittsburgh Five-Year Financial Forecast (FY 2026).

## Files

| File | Rows | Description |
|------|------|-------------|
| target_budget_revenues.csv | 20 | Revenue projections by source (2025-2030) |
| target_budget_expenditures.csv | 8 | Expenditure projections by category (2025-2030) |
| target_budget_reserve_fund.csv | 8 | Reserve fund transfers and balances (2025-2030) |
| target_budget_ratios.csv | 2 | Financial health ratios as percentages (2025-2030) |
| by_department.csv | 28 | Departmental expenditure forecast (2024-2030) |

## Source

`input/split-pdf/04_Five-Year_Financial_Forecast.pdf`

See DATA_DICTIONARY.md for column descriptions.

# Publish the 2027 proposed budget only

**Date:** 2026-11-12
**Status:** accepted

## Context

Besides the 2027 proposed budget, the site also published:
- the full 2026 budget under `/2026/...`: operating index, sections, departments, capital, personnel and "What changed";
- a 2026 amendments page (`/amendments/`);
- a proposed-vs-adopted comparison (`/cross-year/`), built from 2025 and 2026 data;
- four stories and a Stories index, all written about the 2026 budget and built from 2026 data.

The home page and About page pointed into the 2026 archive, and the nav listed all of these pages.

Max asked to "get rid of the 2026 version of pages" (2026-11-12). Max then settled three questions:
- **Stories:** remove all of them.
- **Trends:** keep the `/trends/` page. It charts headline figures across the 2024–2027 documents as history, and isn't a 2026 version of a page.
- **Depth:** stop publishing the archive, but leave its build code and the 2026/2025 data in the repo so it could come back.

## Decision

- **Archive routes:** `ARCHIVE_YEARS` in `web/src/lib/budget-year.ts` is now empty, so no `/2026/...` pages are built. The archive pages, the year registry, the 2026/2025 data views and the amendment-highlighting code all stay in the repo. The home page's "Looking for the 2026 budget?" box and the About page's archive sentence show only when an archive year exists.
- **Deleted pages:**
  - `/amendments/` and `/cross-year/`, plus the components only they used (the cross-year comparison, capital and personnel views);
  - all of `/stories/`, plus the story page layout and the tax-dollar chart only the stories used.
- **Nav:**
  - the Stories menu, which held only Stories and Departments, becomes a plain "Departments" link;
  - the Budgets menu drops "2026 amendments" and "Proposed vs adopted".
  (Our call.)
- **Embeds:** the "biggest budget increases", "biggest budget decreases" and "staffing changes" embeds are removed, along with the Brief's staffing embed button (Max, 2026-11-12). They compared each department's 2027 budget with 2026, the same comparison the client objected to when "What changed" was retired. The Brief's "Who works for the city?" section stays, but without its year-over-year FTE change, new and eliminated position counts and "net change" sentence (Max, 2026-11-12, "they go the way of the embeds"); it keeps the total positions and the headcount chart. Its link-preview description now cites the total positions instead of new positions.
- **Redirects:** Netlify redirects old links (`web/public/_redirects`), so links already shared still land somewhere useful (our call).
  - `/2026/...` and `/2025/...` pages go to the same page in the 2027 budget, for example `/2026/departments/bureau-of-police/` → `/departments/bureau-of-police/`.
  - `/2026/changes/`, `/amendments/`, `/cross-year/` and `/stories/...` go to the home page.
- **Deploy:** `deploy.sh` no longer builds, validates or renders 2026 or 2025 data and images. The trends data reads the regression baselines directly, so it is unaffected.

## Republishing an archive year

1. Add the year back to `ARCHIVE_YEARS`.
2. Restore these `deploy.sh` steps. Data builds go before `build_longitudinal.py`:

   ```bash
   uv run scripts/build_web_data.py --year 2026 --operating-variant amended --output-prefix 2026
   uv run scripts/build_web_data.py --year 2026 --operating-variant adopted --operating-only --output-prefix adopted
   uv run scripts/build_amendment_diff.py --year 2026
   uv run scripts/build_capital_appendices.py --year 2026 --output-prefix 2026
   uv run scripts/build_web_data.py --year 2025 --output-prefix 2025
   ```

   Validation:

   ```bash
   uv run scripts/validate_data.py structural --year 2026 --operating-variant amended
   uv run scripts/validate_data.py outliers --year 2026 --output-prefix 2026
   uv run scripts/validate_data.py cross-year --years 2026,2027 --output-prefix-a 2026 --output-prefix-b ""
   ```

   Images:

   ```bash
   uv run scripts/render_page_images.py --year 2026 --budget-type operating --variant amended
   uv run scripts/render_page_images.py --year 2026 --budget-type capital
   uv run scripts/render_page_images.py --year 2026 --budget-type operating --variant adopted \
     --secondary-of amended --output-subdir pages-adopted \
     --manifest web/src/data/views/2026-adopted-pages.json
   uv run scripts/extract_chart_images.py --year 2026 --operating-variant amended --output-prefix 2026
   ```

3. Remove that year's rules from `web/public/_redirects`.

The amendments page, cross-year page and stories would have to be restored from git history (the commit that introduced this record).

## Consequences

- The 2027 pages still show the 2026 figures that the 2027 document itself prints, such as "2026 budget" columns and the budget chart's year picker. Those come from the 2027 PDF, not the archive.
- The smoke tests now check two things: that none of the removed pages is built, and that no main page links to them.

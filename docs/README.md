# Documentation

Project documentation organized by type:

- **`decisions/`** — Decision records (ADR-lite): what we chose and why. Backward-looking.
- **`plans/`** — Implementation plans and designs. Forward-looking. A plan becomes a decision once acted on.
- **`audits/`** — State-of-the-world snapshots taken before major changes.
- **`notes/`** — Research, observations, and explorations.

## Conventions

- Files are named `YYYY-MM-DD-short-kebab-description.md`
- Each document includes a date and status in its header
- Use `/decision`, `/plan`, or `/audit` Claude skills to create new documents with the correct template

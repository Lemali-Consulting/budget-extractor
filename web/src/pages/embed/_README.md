# Embeds

(Named with a leading underscore: Astro would publish a plain `README.md` in `src/pages/` as a page.)

Frameable copies of three home-page pieces, for Public Source to embed in its stories. They use the `Embed` layout (no site navigation, kept out of search engines, links open in a new tab, and each page tells its frame how tall it is). The embed codes are in `docs/notes/2026-11-17-embed-codes.md`.
